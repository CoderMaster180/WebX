# WebX
WebX 🌐

Explore Beyond Search.

WebX is a lightweight, browser-like web navigation tool built with HTML, CSS, and JavaScript.

It allows users to enter a web address or a search query and open it using their selected search engine or default web browser.

WebX is not a standalone web browser or a search engine. It provides a simple interface for accessing websites and searching the web through existing services.

---

✨ Features

- Multiple Search Engines: Choose between Google, Bing, DuckDuckGo, and Brave.
- Direct URL Navigation: Enter a website address and open it in a new tab.
- Search History: Automatically saves recent searches, with support for deleting individual entries or clearing the entire history.
- Custom Shortcuts: Add and remove shortcuts to your favorite websites.
- Multiple Languages: Supports English, Turkish, German, French, Spanish, Italian, Russian, and Arabic.
- Light & Dark Themes: Switch between light and dark appearances.
- Local Storage: Saves preferences, search history, and shortcuts in the browser's local storage.

🚀 Getting Started

1. Download or clone this repository.
2. Open "index.html" in a modern web browser.
3. Enter a website address or search query.
4. Select your preferred search engine in Settings.
5. Start exploring the web!

No additional libraries or frameworks are required.

⚠️ Limitations

- WebX is not a full-featured web browser.
- Websites open in separate browser tabs.
- Search results are provided by external search engines.
- Internet access is required to open websites and perform searches.
- Saved preferences and data depend on the browser's local storage.
